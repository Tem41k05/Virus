# **App Name**: Detection Demo

## Core Features:

- Keylogger: Simulate keylogging by generating keystroke data and logging it to a keylog.txt file.
- File Access: Simulate unauthorized access to user data by listing file names in a Pictures folder.
- Data Exfiltration: Simulate sending data to a specified email address (e.g., forbadthinhs@gmail.com) by logging a message indicating that keylog.txt and photo list are being sent.
- Webcam Activation: Activate webcam using OpenCV to capture images.

## Style Guidelines:

- Accent: A dark red (#8B0000) to subtly indicate 'danger' or 'alert' status, while not being overly intrusive since the application runs without a GUI.
- Since there is no GUI, focus on a clear, structured approach to any background logging or output that might be generated for debugging.
